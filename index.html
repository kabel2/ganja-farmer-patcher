🌱 Ganja Farmer Patcher

The original Ganja Farmer server has been shut down. This patcher points your original APK to a community server so the game works again. Everything happens in your browser, your file is never uploaded anywhere.

1. Choose the original APK

⬇ Download patched APK

2. Install

  1. If the old original version is installed, uninstall it first (the patched APK has a different signature).
  2. Open the downloaded APK and allow installing from unknown sources.
  3. Samsung: If the installation is blocked, temporarily turn off Auto Blocker under Settings → Security.
  4. On newer devices a notice saying “This app isn't 16 KB compatible…” appears at startup. Just tap OK, the game then runs in compatibility mode.

Good to know

  • Requires Android 7 or newer.
  • Your progress is stored on the server and tied to your installation. Updating with this patcher keeps it, a fresh install starts a new game.
