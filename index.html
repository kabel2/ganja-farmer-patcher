🌱 Ganja Farmer Patcher

Der Originalserver von Ganja Farmer ist abgeschaltet. Dieser Patcher stellt deine Original-APK auf einen Community-Server um, damit das Spiel wieder läuft. Alles passiert in deinem Browser, die Datei wird nirgendwo hochgeladen.

1. Original-APK auswählen

⬇ Gepatchte APK herunterladen

2. Installieren

  1. Falls die alte Original-Version installiert ist: erst deinstallieren (die gepatchte APK hat eine andere Signatur).
  2. Heruntergeladene APK öffnen und die Installation aus unbekannten Quellen erlauben.
  3. Samsung: Falls die Installation blockiert wird, unter Einstellungen → Sicherheit den Auto Blocker vorübergehend ausschalten.
  4. Auf neueren Geräten erscheint beim Start ein Hinweis „This app isn't 16 KB compatible…". Einfach mit OK bestätigen, das Spiel läuft dann im Kompatibilitätsmodus.

Gut zu wissen

  • Läuft ab Android 7.
  • Dein Spielstand liegt auf dem Server und gehört zu deiner Installation. Updates mit diesem Patcher behalten ihn, eine Neuinstallation startet ein neues Spiel.
Inoffizielles Fanprojekt, nicht verbunden mit den Entwicklern von Ganja Farmer. Es wird keine APK bereitgestellt, nur deine eigene Datei verändert.
